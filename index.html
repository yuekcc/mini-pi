项目简介

mp 是一个使用 C3 语言从零实现的编码智能体（coding agent），灵感取自 Pi。它以内置工具与智能体循环（Agent Loop）为核心，对接 OpenAI Chat Completions 兼容接口，在本地完成多轮对话、文件读写、命令执行与子任务编排。

整个项目不依赖重型运行时，编译产物为单一可执行文件。所有与模型的交互均留有审计日志，工程化与可观测性是其设计底色。

  • 原生：纯 C3 实现，仅依赖 libcurl 与 cJSON 两个绑定库。
  • 轻量：编译为单一二进制，无运行时下载，启动即用。
  • 可审计：每次会话写入 ~/.config/mp/workspace/<project>/<sessionId>.jsonl 审计日志。
  • 可扩展：内置 Skill 系统，从全局与本地目录加载 SKILL.md。

核心特性

智能体循环

支持交互模式与 Headless 模式，兼容 OpenAI Chat Completions API，具备多轮对话与工具调用调度能力。

内置工具集

开箱即用的九件工具：文件读写、文本与行哈希双重精确编辑、正则检索、目录列举、Shell 执行与子任务编排。

Skill 系统

自动发现并加载 ~/.agents/skills/ 与 .agents/skills/ 下的能力模块，供系统提示词直接引用。

审计日志

每一轮会话落盘为 JSONL，完整记录请求、工具调用与结果，便于回溯与排查。

AGENTS.md

支持项目级 AGENTS.md，将工程约定注入系统提示词，让智能体理解你的项目。

子 Agent 编排

通过 Task 工具以子进程方式递归调用 mp 自身，将复杂任务拆解为可独立执行的子任务。

内置工具

ReadFile读取文件，带行号与分页
Bash执行 Shell 命令，超长输出自动截断
EditFile按文本精确替换编辑
HashEditFile基于行哈希的精确编辑，支持批量原子提交
WriteFile写入或新建文件，自动建目录
Grep基于 ripgrep 的正则检索
Glob基于 fd 的文件名查找
ListDir列举目录内容（ls -ahl）
Task启动子 Agent 执行子任务

架构设计

程序自入口层启动，构建核心状态与能力系统，进入智能体主循环；循环中按需调用 API 层与工具系统，外部命令最终经由命令执行层落地。

命令行用法

参数说明默认
--config, -c指定配置目录~/.config/mp/
--agent指定智能体角色名称default
--model指定模型 ID（provider/model）Any
--tools允许使用的工具列表（逗号分隔）全部九件
--headless非交互模式，完成任务后退出交互模式
--task, -t指定初始任务内容—
--task-file, -f从文件读取初始任务—
--output-file, -o将末次回复写入文件—
--list-skills列出全部可用 Skill—
--debug转储 HTTP 请求/响应用于排查—
--help, -h / --version, -v帮助信息 / 版本号—

使用示例

交互式命令

在交互模式下，mp 支持以下内置命令（不经过 LLM）：

命令说明
/export将当前对话导出为 Markdown 文件，文件名 <session_id>.md
/clear清空当前对话历史，开启新会话并生成新的 session ID
/exit、/e退出会话，同时显示当前 Session ID
